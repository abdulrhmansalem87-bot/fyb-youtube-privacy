# Fyb website

Public information pages for the Fyb YouTube publishing automation project.

- Home: `index.html`
- Privacy policy: `privacy.html`
- Terms of use: `terms.html`

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

Once GitHub Pages finishes publishing, the expected site URL is:

`https://abdulrhmansalem87-bot.github.io/fyb-youtube-privacy/`

Privacy policy:
`https://abdulrhmansalem87-bot.github.io/fyb-youtube-privacy/privacy.html`

Terms:
`https://abdulrhmansalem87-bot.github.io/fyb-youtube-privacy/terms.html`

Before entering these URLs in Google Auth Platform, confirm that the site is live and check Google's authorized-domain verification requirements. Do not add OAuth secrets or tokens to this repository.
